## What Are The Features You Get With WP Rocket?

Every WP Rocket plan ships the same feature set. No capability is locked behind a higher tier.

1. Page Caching: Creates cached HTML versions of pages so WordPress can serve content with less PHP and database processing.
2. Cache Preloading: Builds cached versions of pages before visitors request them, so pages can load faster from the first visit.
3. CSS Optimization: Minifies CSS files and can remove unused CSS or load CSS asynchronously to reduce the amount of code browsers need to process.
4. JavaScript Optimization: Minifies JavaScript, loads scripts with defer, and can delay JavaScript until a visitor interacts with the page.
5. Image LazyLoad: Delays images, background images, videos, and iframes until they are needed, which can reduce the initial page load.
6. Critical Image Optimization: Identifies important above-the-fold images and gives them priority instead of applying lazy loading to them.
7. Browser Caching: Stores frequently used website resources in the visitor's browser, reducing the need to download the same files again.
8. GZIP Compression: Compresses web pages on the server before sending them to visitors, reducing the amount of data transferred.
9. Database Cleanup: Removes unnecessary revisions, auto-drafts, spam comments, trashed comments, and expired transients to keep the WordPress database cleaner.
10. CDN Support: Connects WP Rocket with a CDN and supports integrations such as Cloudflare, while RocketCDN provides another option for delivering website assets closer to visitors.
11. eCommerce Optimization: Excludes sensitive shopping and checkout pages from caching to help prevent caching from interfering with purchases.
12. Google Fonts Optimization: Can optimize Google Fonts and, where supported, host them locally to reduce external requests.
13. Heartbeat Control: Lets you reduce WordPress Heartbeat activity when it creates unnecessary server requests.
14. Rocket Insights: Gives you a performance monitoring area inside WP Rocket with page-level performance information and recommendations.

## What is WP Rocket?

WP Rocket is a premium WordPress caching and performance plugin launched in 2013 by WP Media. It helps websites load faster through page caching, CSS and JavaScript optimization, lazy loading, browser caching, and database cleanup.

WP Rocket also includes tools such as Rocket Insights and RocketCDN to help monitor and improve website performance.

WP Rocket is currently used on more than [5.5 million websites worldwide](https://wp-rocket.me/press).
